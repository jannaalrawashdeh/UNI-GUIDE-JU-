Uni Guide is an AI-powered web-based student assistant system developed for the University of Jordan. It helps students access university regulations, policies, and procedures through an intelligent bilingual chatbot that supports Arabic and English. The system uses AI and document retrieval technology to provide relevant answers based on official university documents. It also includes student account management and an administrator module for managing and updating university documents. Uni Guide aims to simplify access to university information, save students time, and improve their overall university experience.
